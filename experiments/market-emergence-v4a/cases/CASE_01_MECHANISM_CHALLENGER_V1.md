# Case 01 Mechanism Challenger v1

Case: Semiconductor synchronized rise  
Evidence base: Case 01 real snapshot v1 + Evidence Upgrade v2  
Authority: mechanism research only; no causal probability, trading, sizing, or execution authority.

## Question

The first two counterfactuals are deliberately simple:

- A — Theme expectation repricing: change the semiconductor economic reference anchor; no exogenous common buying.
- B — Common theme flow: inject a finite common buy program; do not change the economic reference anchor.

The question is not which curve looks prettier. It is which single-mechanism counterfactual is compatible with the observable real-market fingerprint, and where each one fails.

## Comparison language

The challenger uses only MATCH, PARTIAL, CONFLICT, and UNKNOWN.

It does not convert sparse evidence into a causal probability.

## Real observable fingerprint

1. SPY, QQQ, and the semiconductor basket all moved up immediately after the 08:30 ET labor release.
2. The semiconductor basket outperformed both SPY and QQQ in the short event window.
3. The basket gained about 1.04% from 08:29 to 09:00 ET.
4. By the close, only roughly one fifth of that initial event-window gain remained.
5. The 09:30–16:00 ET semiconductor equal-weight return was negative.
6. MU has direct single-name expectation evidence: forward guidance above event-time consensus.
7. Available SOXQ / SMH proxies do not show an obvious ETF-creation wave.
8. Direct signed flow, historical depth/spread, and return-to-future-flow remain unavailable.

## A — Theme expectation repricing

MATCH — Theme relative excess. A theme-level reference-anchor shift naturally creates semiconductor excess versus the broad market.

PARTIAL — Direct expectation evidence. MU provides direct expectation evidence, but only for one name.

CONFLICT — Broad-market synchronized start. The real move begins simultaneously in SPY, QQQ, and semiconductors; A currently acts only on the semiconductor theme.

CONFLICT — Path persistence. A continues converging toward a new reference anchor, while the real path gives back most of the initial event-window move.

Therefore A is partial but insufficient as a complete single-mechanism explanation.

## B — Common theme flow

MATCH — Short-term path shape. A finite common buy program creates a rise and partial reversal, similar to the real event-window rise followed by give-back.

MATCH — Theme relative excess. Theme-specific flow can create semiconductor excess versus the broad market.

CONFLICT — Broad-market synchronized start. B is currently a semiconductor-only flow event and cannot independently explain simultaneous SPY / QQQ movement.

UNKNOWN — Direct flow evidence. Available ETF proxies do not show an obvious creation wave, but AUM and trading volume are not signed flow.

Therefore B has the better path-shape match but remains unconfirmed.

## Challenger result

NEITHER SINGLE MECHANISM IS SUFFICIENT.

A has the better direct expectation evidence.

B has the better short-term path-shape match.

Both fail as complete single-mechanism explanations because the real event begins as a broad-market move around the macro release.

Next hypothesis:

Macro Common Repricing + Heterogeneous Theme / Stock Expectations + Optional Flow Amplifier.

The flow term remains optional until direct flow evidence exists.

## Decisive evidence queue

P0:
1. Theme-level synchronized earnings/revenue estimate revisions.
2. ETF / stock signed flow or OFI.

P1:
3. Event-window bid-ask spread, depth, and impact-per-unit-flow.
4. Return → Future Flow series.

## Development implication

Do not tune A or B to force one to win.

The evidence has identified a missing mechanism class.

The next simulator checkpoint should add a separately testable macro common repricing mechanism and then allow heterogeneous theme / stock expectation shocks to layer on top. Common flow should remain a separately switchable amplifier, not a default explanation.
