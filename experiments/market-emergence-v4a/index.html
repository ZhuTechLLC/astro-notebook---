一个大型机构内部可能同时包含主动基本面、指数、CTA、统计套利和执行算法。因此分类单位不是公司名称，而是“什么信号触发什么订单”。

常见足迹：热门标的成交集中、短期期权活跃

04 · REACTION FUNCTIONS

颜色和形状只是标签，真正差异写进反应函数

同一个价格变化，不同参与者会得到完全不同的交易方向。V4A 至少实现六种不同的局部规则，而不是所有节点共享同一个 Boids 方程。

散户 / Attentionqᵢ = α·Attention + β·Momentum + εᵢ

对注意力、涨幅和噪声最敏感。

主动基本面qᵢ = α·(V - P) + β·InfoShock

资本较大、反应较慢，偏离价值时倾向逆向。

CTA / Trendqᵢ = α·Momentum - β·Volatility

趋势越强越跟随，波动过高限制风险预算。

StatArbqᵢ = -α·Residual - β·ShortMove

提供均值回复力量，吸收局部失衡。

Dealerqᵢ = f(Inventory, Hedge, Shock)

V4A 先做库存与对冲简化，后续再接真实 Greeks。

HFT / MMqᵢ = -α·MicroMove - β·Inventory

高频、小资本、短周期流动性供给。

订单汇聚Qⱼ,ₜ = Σᵢ qᵢⱼ,ₜ
价格与网络传播ΔPⱼ,ₜ = λⱼ,ₜQⱼ,ₜ + ΣₖWⱼₖΔPₖ,ₜ + εⱼ,ₜ
反馈Xₜ₊₁ = G(Pₜ, Qₜ, Networkₜ)
05 · ORDER PARAMETERS

第一版最小状态向量：六个量

每个状态量必须同时满足：定义清楚、可从真实数据构造、能做 PIT 回测、与其它量不是简单重复。

A

同步度 Alignment

Aₜ = |Σᵢωᵢsᵢ,ₜ| / Σᵢωᵢ

市场方向是否越来越一致。第一版用收益方向、广度和资金流方向做代理。

MVP 可做
C

耦合度 Coupling

Cₜ = λ₁(Σₜ) / tr(Σₜ)

相关矩阵第一共同模态占比。上升意味着资产独立性下降、共同驱动增强。

MVP 可做
Q

拥挤度 Crowding

Qₜ ≈ HHI(exposure, flow, ownership)

资金是否挤在相似暴露上。用 ETF 流、因子、持仓重叠与成交集中度重建。

部分可做
L

流动性脆弱度

Δpₜ = βₜ·OFIₜ + εₜ

同样订单流失衡需要多大价格变化才能被吸收。β 越大，系统越脆弱。

先代理，后深度
E

内生性 Endogeneity

Eₜ = ρ(Kₜ), Kᵢⱼ = ∫φᵢⱼ(τ)dτ

事件有多少是由过去事件继续激发。完整实现需要逐笔/订单事件级数据。

需高频数据
P

传播度 Propagation

Pₜ = ρ(Bₜ)

冲击是否从龙头、行业、供应链或因子网络向其它资产继续扩散。

MVP 可做
06 · MARKET PHENOMENA

股市现象，不再只是“涨跌”，而是状态签名

同样是上涨，如果背后的同步、传播、拥挤与流动性结构不同，后续路径和风险性质可能完全不同。

趋势 / 动量持续性反馈
A ↑P ↑E ↗C ↗

越来越多参与者对既有方向作出同向反应，价格变化成为下一轮交易的输入。

板块扩散局部 → 中观
P ↑↑A 局部↑C 局部↑

真正的“扩散”应表现为 lead-lag 网络增强，而不只是多只股票同日上涨。

拥挤 / 泡沫资本同质化
Q ↑↑A ↑C ↑κ → 1

策略收益吸引更多同类资本，价格上行又强化收益和叙事，形成正反馈。

流动性踩踏非线性风险
L ↑↑C ↑↑E ↑↑P ↑↑

卖出、撤单、对冲和去杠杆互相强化，同样的卖盘开始造成更大的价格位移。

均值回复扰动衰减
P ↓E 低κ ≪ 1

冲击无法持续自我激发，流动性提供者和逆向资金逐步吸收偏离。

状态切换Regime Change
ΔZ 大κ 变化

研究重点不是命名牛熊，而是识别 Zₜ 的组合是否跨越了稳定结构的边界。
