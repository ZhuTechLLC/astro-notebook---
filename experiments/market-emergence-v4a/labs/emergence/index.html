03 · 市场参与者

理解市场时，与其按机构名称分类，不如看资金如何决策：它依据什么信息、受什么约束、以什么速度交易。一个大型机构内部也可能同时存在多种完全不同的交易逻辑。

04 · 数学模型

用数学描述不同参与者的交易反应

同样的价格变化可能触发追涨、均值回复、对冲或流动性提供。下面的简化方程用于说明这些行为差异如何进入订单流。

散户 / 注意力资金qᵢ = α(1+γ·Attention)(β·Momentum+δ·InfoShock)+εᵢ

注意力放大已有方向信号，本身不被当作固定的正向买入信号。

主动基本面qᵢ = α·(V - P) + β·InfoShock

资本较大、反应较慢，偏离价值时倾向逆向。

趋势策略qᵢ = α·Momentum / (1 + γ·Volatility)

趋势越强越跟随，波动越高时缩小反应强度；这里只是简化的波动缩放。

统计套利qᵢ = α·(V-P) - β·ShortMove

当价格低于示意价值时倾向买入，高于价值时倾向卖出，并对短时价格变化逆向。

做市 / 库存对冲qᵢ = f(Inventory, ShortMove, Shock)

当前模型只表达库存与短时价格响应，不把它冒充为真实期权 Gamma、Vanna 或 Charm 对冲。

高频做市qᵢ = -α·MicroMove - β·Inventory

高频、小资本、短周期流动性供给。

订单汇聚Flowⱼ,ₜ = Σᵢ qᵢⱼ,ₜ
示意价格更新ΔPⱼ,ₜ = λⱼ,ₜFlowⱼ,ₜ + ΣₖWⱼₖΔPₖ,ₜ + εⱼ,ₜ
反馈Sₜ₊₁ = F(Sₜ, Pₜ, Flowₜ)
05 · 概念与估计器

不预设固定状态向量

每个投资问题先区分 Observable、Mechanism、Estimator 与 Evidence。下面只是当前实验和研究中会用到的对象示例；是否进入状态摘要由具体数据、期限和决策价值决定。

FLOW

订单流方向一致性

alignment_sim = |Σᵢwᵢqᵢ| / Σᵢwᵢ|qᵢ|

当前模拟可直接计算的订单方向摘要。它不是收益 breadth，也不是持仓拥挤度。

模拟输出
FLOW HHI

订单流集中度

HHI(flow share)

描述当期交易活动是否集中到少数资产。只有持仓、暴露、资金集中和退出容量等证据齐备时，才使用 Crowding。

模拟输出
IMPACT

Price Impact

Δpₜ = β_OFI,ₜ·OFIₜ + εₜ

资金流或订单流对价格的条件响应。它是流动性的一个维度，不等同于 Liquidity 本身。

需成交 / 报价数据
R→F

Return–Flow Response

E[Flowₜ₊ₕ | Returnₜ]

价格变化与后续资金流响应的关系。没有识别设计时只称 response，不写成因果反馈。

需资金流与时间结构
MODE

Common-Mode Movement

λ₁(Rₜ) / tr(Rₜ)

横截面共同运动的统计摘要。只有明确因子模型时才使用 Common Factor。

统计估计
HAWKES

Self-Excitation

λᵢ(t)=μᵢ+Σⱼ∫φᵢⱼ(t-s)dNⱼ(s)

只在显式 Hawkes 类事件模型中使用，自激不是趋势、模仿或反馈的泛称。

需事件级数据
NET

Connectedness / Spillover

IRFᵢⱼ(h) · FEVDᵢⱼ(h) · lead-lag

连通性和 spillover 必须绑定具体方法、方向与期限；Transmission 还需要明确经济通道与识别证据。

方法依问题选择
LIQ

Liquidity / Depth / Resiliency

spread · depth · impact · recovery

流动性是多维概念。深度、价格冲击和冲击后的恢复速度分别记录，不压成一个万能分数。

同样的涨跌，背后的机制可能完全不同

这里列的是待检验的结构特征，不把一个统计摘要直接升级成因果解释。真实分析必须同时保留竞争机制和 UNKNOWN。

趋势 / 动量持续性反馈

价格变化可能成为下一轮交易的输入，但必须与共同信息、基本面重估等竞争解释区分。

板块扩散局部 → 中观
有向传导 ↑期限明确

扩散需要 lead-lag、脉冲响应或连通性等方向证据，而不只是多只股票同日上涨。

持仓或资金流集中只是证据之一；真正风险还取决于共同约束、流动性与退出路径。

价格冲击 ↑深度 ↓受约束流 ↑?
