# 4.7 产业链分析与板块内涨幅因子

**核心摘要：**

> 同一板块内，个股涨跌幅度差异往往大于板块本身。本节给出可复用的**产业链分析框架**与**板块内弹性因子**，并与主题生命周期（S0–S4）对齐。本页是研究方法论，不产生买卖指令；执行须经交易前检查与人工确认（`recommendation_only_no_order_submission`）。

## 1. 通用产业链分析框架（八问）

对任意主题（AI、机器人、新能源等）固定按序回答：

| # | 问题 | 目的 |
|---|---|---|
| 1 | 需求终点是谁？ | 云厂商 capex、终端、政策采购等 |
| 2 | 当前真正瓶颈在哪一层？ | 算力 / 带宽 / 存储 / 电力散热 / 封装 |
| 3 | 主题处在 S0–S4 哪一段？ | 宽度、资金、龙头是否同向 |
| 4 | 各层收入纯度如何？ | 避免“沾边票”假映射 |
| 5 | 角色分层：龙头、中军、跟随、掉队 | 决定跟踪优先级与弹性预期 |
| 6 | 估值与拥挤：谁定价充分？ | 赔率与回撤幅度 |
| 7 | 失效条件是什么？ | 龙头破位、宽度塌陷、指引下修 |
| 8 | 动作带是什么？ | 观察 / shadow / 回踩确认 / 减风险 |

**分析顺序：** 先定主题阶段 → 再定瓶颈层 → 再定角色 → 最后才看单票弹性。

## 2. 板块内涨幅：主要相关因素

| 层级 | 因素 | 含义 |
|---|---|---|
| 角色地位 | 龙头 / 中军 / 跟随 / 掉队 | 龙头辨识度与带动最强；跟随弹性大但持续性差 |
| 产业链位置 | 瓶颈 vs 产能过剩 | 稀缺环节弹性常大于充分竞争环节 |
| 收入映射纯度 | 主题收入占比、客户集中度 | 真正吃到订单的涨得狠 |
| 景气兑现 | 指引、订单、毛利率 | 决定能涨多久 |
| 结构位置 | Stage、相对强弱、乖离、拥挤 | 健康确认段赔率较好；过热段波动大 |
| 主题阶段 | Theme S0–S4 | S1–S2 扩散：龙头先、中军确认、后排补涨；S4：弹性股杀更狠 |
| 资金与流动性 | 成交额、ETF 流入、市值 | 抱团抬升弹性，反转时回撤也更大 |
| 估值与利率敏感度 | PE/PEG、久期 | 高估值成长在利率上行时下行更陡 |
| 事件催化 | 财报、产品、政策、地缘 | 同板块内有明确催化者振幅更大 |

一句话：**板块决定方向，产业链位置 + 角色分层 + 主题阶段决定幅度；业绩与资金决定能否持续。**

---

## 3. 角色分层定义

| 角色 | 识别要点 | 常见用法 |
|---|---|---|
| 龙头 | 辨识度最高、带动最强、资金最集中 | 定主题方向；不宜在 S3 末端盲追 |
| 中军 | 容量大、稳定性高、确认题材 | 验证扩散是否成立 |
| 跟随 | 情绪带动、自主地位弱 | 弹性大，退潮回撤也大 |
| 掉队 | 同主题下表现显著落后 | 先问“为何掉队”，勿机械补涨 |

---

## 4. 主题生命周期 S0–S4（简表）

| 阶段 | 名称 | 典型信号 | 允许动作倾向 |
|---|---|---|---|
| S0 | 潜伏 | 仅有政策/研报，无宽度 | 影子跟踪 |
| S1 | 验证 | 少数龙头转强，宽度偏低 | 小仓位侦察研究 |
| S2 | 扩散 | 宽度与资金确认，龙头回踩承接 | 分批验证（仍须检查） |
| S3 | 加速 | 集群大涨、拥挤升高 | 持有为主，限制新开 |
| S4 | 衰竭 | 龙头破位、宽度塌陷 | 减风险、主题级止损纪律 |

详细教义见 TRQuant：`context/THEME_LIFECYCLE_EARLY_LAYOUT_AND_EXIT_DOCTRINE_v1.md`。

## 5. 示例：AI 算力四层链（L1–L4）

```text
L1 算力核心（GPU/ASIC/平台）
    → L2 互连与光通信（带宽瓶颈）
        → L3 存储 / 设备 / 材料 / 先进封装
            → L4 服务器 / 电源液冷 / PCB / 应用与端侧
```

| 层级 | 特征 | 弹性与风险 |
|---|---|---|
| L1 平台龙头 | 辨识度高 | beta 高，常相对强于二线，但仍受估值与利率约束 |
| L2 互连/代工 | 瓶颈叙事强时弹性大 | 退潮时回撤也大 |
| L3 存储/设备 | 跟资本开支与库存周期 | 预期差驱动振幅 |
| L4 扩散环节 | 弹性最大、纯度分化大 | 概念股假映射风险最高 |
