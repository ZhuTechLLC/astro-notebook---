# 2.5 每日板块轮动阶段代理卡

**核心摘要：**

> 用板块 ETF（如 XLV/XLE/XLF vs SMH/XLK/XLB）的相对强弱，结构化推断市场所处阶段。轮动能引证**风格与领导层**，不能单独给**经济周期**盖章。每个假说必须有确认条件与失效条件。本页为研究与复盘工具，不是下单授权。

> **权威合同：** TRQuant 仓库 `context/US_SECTOR_ROTATION_STAGE_PROXY_TEMPLATE_v1.md`。本页为手册体例镜像；若冲突以 TRQuant context 为准。

## 0. 使用原则（强制）

1. **轮动代理可引证“市场风格阶段”，不能单独给经济周期盖章。**
2. 必须同时输出三层判档：市场微观阶段、经济周期假说、主题生命周期。
3. 每个假说必须有：支持证据 / 反对证据 / 确认条件 / 失效条件 / 动作带。
4. 动作带默认：`WAIT_SELECTIVE` / watchlist / shadow；不得因轮动强弱直接 EXECUTE。
5. 20 日收益是默认窗口；同时记录 5 日与 60 日。

边界：`recommendation_only_no_order_submission`。

## 2. 代理读法与周期映射

### 2.1 核心代理

| 角色 | ETF | 读法 |
|---|---|---|
| 成长领导 | XLK、SMH、QQQ | SMH 弱于 XLK = 硬件链更深调整 |
| 防御 | XLV、XLP、XLU | 防御偏好是否上升 |
| 周期/通胀 | XLE、XLB、XLI | 后期扩张 vs 中期扩张分辨器 |
| 金融/利率 | XLF、XLRE | 金融强削弱危机式衰退；金融转弱抬升衰退概率 |
| 风险偏好 | SPY、IWM、VIX | 结构牛/熊与恐慌温度；缺数据标 `missing` |

### 2.2 经典映射速查（对接 §2.2）

| 若 20d 呈现… | 更像… | 不太像… |
|---|---|---|
| 金融+科技+可选强，防御弱 | 早期扩张 | 衰退 |
| 工业+材料+地产强 | 中期扩张 | 后期扩张/衰退 |
| 能源+必需/公用强，成长掉队 | 后期扩张 | 早期扩张 |
| 医疗+必需+公用强，周期/高 beta 弱，金融也弱 | 衰退旁证增强 | 早期扩张 |
| 防御/价值强，但 SPY 结构未破、金融仍强 | 牛市内再平衡/切换 | 已确认萧条 |

## 3. 固定假说库 H1–H5

### H1 后期扩张 / 软着陆再平衡

- 支持：XLE↑、防御↑、XLK/SMH↓、材料不强  
- 反对：工业/材料全面走强且科技重新领涨  
- 确认：利率/通胀压力持续 + 成长估值继续压缩 + 防御相对收益延续 2–4 周  
- 失效：利率明显回落 + SMH/XLK 收复 MA20/50 并带动 SPY 新高  

### H2 牛市内成长→价值/防御轮动

- 支持：SPY 结构未破；XLV/XLF 相对强；VIX 不恐慌  
- 反对：SPY 破关键 + 信用利差急扩  
- 确认：金融与医疗持续强于科技 2 周+  
- 失效：广谱风险资产共振下跌，或科技重新夺取领导权  

### H3 AI/半导体主题 S3→S4

- 支持：SMH 显著弱于 SPY/XLK；高拥挤个股回撤更大  
- 反对：宽度回升、龙头重回关键均线、指引上修且价格确认  
- 确认：主题宽度塌陷 + 龙头放量破位 + 资金连续流出  
- 失效：SMH 收复 MA20/50 + 主题宽度修复  

### H4 已确认衰退

- 支持：XLF 转弱 + HY 利差走阔 + 盈利下修扩散 + 就业恶化  
- 反对：金融仍强、信用稳定、SPY 结构完好  
- 确认：上述至少 3 项同时成立  
- 失效：金融修复 + 信用收窄 + 周期板块企稳  

### H5 早期/中期扩张重启

- 支持：金融+科技或工业+材料重新领涨  
- 反对：SMH/XLK 持续大幅落后且材料偏弱  
- 确认：领导层切换回成长/周期并维持 3–4 周  
- 失效：再次回到能源/防御占优、成长掉队

## 4. 工作实例：2026-07-18

> 数值以当日研究会话提供的 20 日代理为准；完整定档仍需 SPY/VIX/信用/利率补证。

| 代理 | 20d % | 角色 |
|---|---:|---|
| XLV | +7.35% | 强：防御/医疗 |
| XLE | +6.26% | 强：能源/通胀尾部 |
| XLF | +4.45% | 强：金融/价值 |
| XLB | -2.50% | 弱：材料 |
| XLK | -5.38% | 弱：科技 |
| SMH | -10.81% | 最弱：半导体 |

**三层判档：**

| 层级 | 判档 | 置信度 |
|---|---|---|
| 市场微观阶段 | 切换（偏防守） | 高 |
| 经济周期假说 | 后期扩张 / 再平衡旁证 | 中 |
| 主题阶段(AI) | S3→S4 | 高 |
| 动作档 | WAIT_SELECTIVE | 高 |

**假说：** H1/H2/H3 保留；H4 降级观察；H5 淘汰倾向。

**综合：** 市场在交易“成长拥挤后的再平衡”，带后期扩张板块特征；AI/半导体退潮证据强，但大盘未给出确认衰退信号。
